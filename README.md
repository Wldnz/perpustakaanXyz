Go To `github.com/Wldnz/perpustakaanXyz/releases/tag/testing-phase`, scroll down then download perpustakaanxyz.apk

# How To Use Website To Manage Library  
First, Go To `perpustakaanxyz.wldnz.xyz` or `perpustakaanxyz.wldnz.xyz/login`.  
Second, Login as Admin or Staff (Credentials at `github.com/Wldnz/perpustakaanXyz/releases/tag/testing-phase`)  
Finally, You Can Manage Members, Books, Request Verification, Request Verification Book, History Of Borrowed Books, etc.
